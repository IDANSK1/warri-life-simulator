How to Host as a Real Website

Deploy this game online for free as a custom live URL using GitHub & Vercel:

Step 1: Upload to GitHub

  1. Save this file on your computer as index.html.
  2. Go to GitHub.com and log in.
  3. Create a new repository named warri-life-simulator.
  4. Click "uploading an existing file", drag index.html, and click Commit Changes.

Step 2: Deploy on Vercel

  1. Go to Vercel.com and sign in with GitHub.
  2. Click "Add New" → "Project".
  3. Import your warri-life-simulator repository.
  4. Click Deploy. Vercel will generate your live link (e.g. warri-life.vercel.app) in 10 seconds!
